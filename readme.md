# Banana 1 - SpacedPeel
Author: Justin Cockrell

## Concept
SpacedPeel is a lightweight tool that helps teachers send sets of questions to students via email using spaced repetition. Teachers can track responses and reinforce learning without manual effort.

## Problem Statement
Teachers don't have an easy way to send personalized questions to help students progress and learn at their own pace.

## MVP
- JSON file defines a set of questions.
- Node.js script sends questions to students via email.
- Responses collected via email or a Google Sheet.

## Target Users
High school or college teachers who want to automate spaced repetition for their students.
